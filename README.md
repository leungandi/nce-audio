# nce-audio

[新概念英语精听学习站](https://leungandi.github.io/nce-player/) 的音频资源仓库。

- `audio/nce2-01.m4a` … 课文音频，AAC 单声道 64 kbps
- 命名规则：`nce{册号}-{课号}.m4a`
- 由站点仓库的 `tools/build-book.mjs` 生成，不要手工改动

站点通过 `https://leungandi.github.io/nce-audio/audio/<id>.m4a` 引用。

## 版权

音频素材来源于互联网，仅作个人学习研究使用，本仓库不拥有版权。强烈建议支持正版。
